## 2. Основные типы данных

| Тип в Python | Пример из проекта | Что это такое |
|---|---|---|
| `int` | `45` | Целое число (секунды таймера) |
| `float` | `0.15` | Дробное число (пауза в секундах `time.sleep(0.15)`) |

## 3. Аннотации типов (`typing`)

Python позволяет явно указывать типы аргументов и возвращаемых значений, чтобы код было легче читать:

```python
from typing import Optional, Tuple, List

# Функция принимает строку (text: str), логический флаг (enabled: bool)
# и возвращает кортеж из трех элементов (Tuple[str, List[str], int]):
def sanitize_text(text: str, clean_urls_enabled: bool = True) -> Tuple[str, List[str], int]:
    ...

# Optional[str] означает: функция вернет либо строку str, либо None (если в буфере пусто)
def read_clipboard_text() -> Optional[str]:
    ...
```

## 4. Списки, генераторы и срезы (Slices)

В Python срезы позволяют легко обрезать строки и списки:

```python
# 1. Срез строки:
text = "sk-proj-1234567890abcdef"
masked = f"{text[:4]}•••{text[-2:]}"   # text[:4] — первые 4 символа ("sk-p")
                                       # text[-2:] — последние 2 символа ("ef")
                                       # Результат: "sk-p•••ef"

# 2. Ограничение последних записей лога:
_log_lines[-25:]                       # Взять ровно 25 последних строк из списка

# 3. Разворот списка/строки задом наперёд:
digits[::-1]                           # Используется в алгоритме Луна для проверки карт с конца
```

## 5. Классы и объектно-ориентированное программирование

Класс — это чертёж, по которому создаются объекты:

```python
class GhostTimer:
    def __init__(self):
        # __init__ — это конструктор. Он вызывается при создании объекта: timer = GhostTimer()
        self._lock = threading.Lock()   # Атрибут экземпляра: мьютекс для защиты памяти
        self._remaining = 0             # Сколько секунд осталось
        self._armed = False             # Взведен ли таймер

    def arm(self, seconds: int, desc: str):
        # Метод (функция внутри класса). Первый аргумент всегда self (ссылка на сам объект)
        with self._lock:
            self._remaining = seconds
            self._armed = True
```

## 6. Многопоточность (`threading`) и защита от гонок (`Lock`)

Когда две части программы работают одновременно (например, один поток читает буфер, а второй ждет нажатия клавиш от пользователя):

```python
import threading

# 1. Запуск функции в фоновом (фоновом/daemon) потоке:
key_thread = threading.Thread(target=run_key_listener, daemon=True)
key_thread.start()
# daemon=True означает: поток автоматически завершится, когда закроется главная программа.

# 2. Защита общих данных через Lock (мьютекс):
_ui_lock = threading.Lock()

with _ui_lock:
    # Блок внутри with _ui_lock может выполнять только ОДИН поток одновременно.
    # Другие потоки подождут своей очереди, пока этот блок не закончится.
    print(msg)
```

## 7. Обработка ошибок (`try ... except ... finally`)

```python
try:
    # Потенциально опасное действие (например, вызов системной функции Windows)
    res = user32.OpenClipboard(None)
except Exception as e:
    # Сработает, только если произошла ошибка
    print(f"Ошибка: {e}")
finally:
    # Сработает ВСЕГДА (даже если внутри try произошел краш или return!)
    # Критически важно для освобождения системных ресурсов Windows:
    user32.CloseClipboard()
```

## 8. Регулярные выражения (`re`)

Регулярные выражения позволяют искать сложные текстовые шаблоны:

```python
import re

# re.compile заранее компилирует шаблон в память (работает в разы быстрее)
SECRET_PATTERN = re.compile(r"sk-[a-zA-Z0-9_\-]{20,}")
# Что это значит:
#   sk-          — начинается строго с букв "sk-"
#   [a-zA-Z0-9]  — далее идут любые буквы или цифры
#   {20,}        — длиной не менее 20 символов

# Поиск в тексте:
if SECRET_PATTERN.search(text):
    print("Найден ключ OpenAI!")

# Замена в тексте:
# URL_REGEX.sub(замена, текст) находит все ссылки и заменяет их на очищенные
```

## 9. Системные вызовы через `ctypes`

`ctypes` превращает Python в инструмент уровня C/C++:

```python
import ctypes
from ctypes import wintypes

# 1. Загружаем системные DLL Windows:
user32 = ctypes.windll.user32      # Окна, буфер обмена, меню
kernel32 = ctypes.windll.kernel32  # Память, процессы, консоль

# 2. Указываем типы данных для 64-битной Windows:
user32.OpenClipboard.argtypes = [wintypes.HWND]   # Принимает дескриптор окна
user32.OpenClipboard.restype = wintypes.BOOL      # Возвращает True/False (успех/ошибка)

# 3. Вызываем напрямую функцию операционной системы:
seq = user32.GetClipboardSequenceNumber()
```

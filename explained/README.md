# 🎓 GhostClip — учебная копия с объяснениями

Это **полная рабочая копия** проекта, в которой почти каждая строчка объяснена комментарием на русском.
Логика кода **не изменена**: эта версия работает так же, как оригинал.

> Оригинал лежит в корне проекта и не тронут. Здесь можно спокойно читать и экспериментировать.

## 📖 В каком порядке читать

| № | Файл | Почему именно сейчас |
|---|---|---|
| 0 | [00_ОСНОВЫ_PYTHON.md](00_ОСНОВЫ_PYTHON.md) | Основы языка. Без этого дальше будет тяжело |
| 1 | [ghostclip/config.py](ghostclip/config.py) | Самый простой: просто настройки «вкл/выкл» |
| 2 | [ghostclip/detector.py](ghostclip/detector.py) | Как программа понимает, что текст похож на пароль или карту |
| 3 | [ghostclip/cleaner.py](ghostclip/cleaner.py) | Чистка ссылок и невидимых символов |
| 4 | [ghostclip/audit.py](ghostclip/audit.py) | Запись в лог-файл |
| 5 | [ghostclip/clipboard.py](ghostclip/clipboard.py) | Работа с буфером обмена Windows (сложнее, тут ctypes) |
| 6 | [ghostclip/shredder.py](ghostclip/shredder.py) | Стирание буфера и истории Win+V |
| 7 | [ghostclip/timer.py](ghostclip/timer.py) | Таймер самоуничтожения (тут потоки) |
| 8 | [ghostclip/\_\_init\_\_.py](ghostclip/__init__.py) | «Витрина» пакета |
| 9 | [main.py](main.py) | Главный файл: здесь всё соединяется вместе |
| 10 | [ghostclip/tray.py](ghostclip/tray.py) | Иконка в трее. **Самый сложный**, читай последним |

## 🗺️ Как всё связано

```
                 main.py  (главный цикл + клавиатура)
                    │
     ┌──────────────┼───────────────┬───────────────┐
     ▼              ▼               ▼               ▼
 clipboard.py   cleaner.py     detector.py      tray.py
 (читать/писать (чистить        (это секрет?)   (иконка, меню)
  буфер)         ссылки)            │
     ▲                              ▼
     │                          timer.py ──► shredder.py (стереть всё)
     │                              │
     └──────────────────────────────┴──► audit.py (записать в лог)

              config.py — настройки, их читают все
```

## ▶️ Как запустить учебную копию

```
python explained/main.py
```

## 💡 Совет

Почти все приёмы, которые встречаются в этом проекте, объяснены в этой папке.

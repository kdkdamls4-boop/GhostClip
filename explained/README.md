## 🏛️ Архитектура: как все модули связаны между собой

Программа работает в **трех параллельных потоках**, которые не мешают друг другу:

```
                      ┌──────────────────────────────────────────────┐
                      │              ПОТОК 1 (Главный):              │
                      │             run_monitor() в main.py          │
                      │  Опрашивает GetClipboardSequenceNumber()     │
                      │              (0% нагрузки на CPU)            │
                      └──────────────────────┬───────────────────────┘
                                             │
                       При изменении буфера: │
                                             ▼
                     ┌──────────────────────────────────────────────┐
                     │ 1. ghostclip/cleaner.py                      │
                     │    Очищает URL от меток слежки (utm, fbclid) │
                     │    Вырезает невидимые Zero-Width знаки       │
                     └──────────────────────┬───────────────────────┘
                                             │
                                             ▼
                     ┌──────────────────────────────────────────────┐
                     │ 2. ghostclip/detector.py                     │
                     │    Проверяет карты по алгоритму Луна         │
                     │    Считает энтропию паролей по Шеннону       │
                     │    Ищет токены (OpenAI, GitHub, AWS)         │
                     └───────┬──────────────────────────────┬───────┘
                             │                              │
                   Если найден секрет:             Обычный безопасный текст:
                             │                              │
                             ▼                              ▼
      ┌──────────────────────────────────┐        ┌──────────────────┐
      │ 3. ghostclip/timer.py (ПОТОК 2)  │        │ Живой лог на     │
      │    Запускает 45-сек. таймер      │        │ экране консоли   │
      │    При истечении вызывает        │        └──────────────────┘
      │    shredder.py (затирка + Win+V) │
      └──────────────────────────────────┘

                      ┌──────────────────────────────────────────────┐
                      │              ПОТОК 3 (Трей):                 │
                      │          ghostclip/tray/manager.py           │
                      │  Иконка щита возле часов + нативное ПКМ-меню │
                      │  Переключатели [1-6], очистка, паника        │
                      └──────────────────────────────────────────────┘
```

## 🔑 Ключевые термины простыми словами

* **Win32 API** — набор функций, встроенных в саму Windows (создание окон, работа с буфером, меню, памятью). Написан на языке Си.
* **`ctypes`** — стандартная библиотека Python, которая позволяет вызывать функции Windows напрямую из системных DLL (`user32.dll`, `kernel32.dll`, `shell32.dll`) без установки сторонних пакетов.
* **Алгоритм Луна** — математическая формула контрольной суммы банковских карт (Visa, MasterCard, МИР), которая отличает настоящие номера карт от случайного набора 16 цифр.
* **Энтропия Шеннона** — показатель информационной случайности строки. Сгенерированный пароль со спецсимволами (`vX9#mQ2$pL!8`) имеет высокую энтропию ($\ge 3.75$ бит/символ), а обычные слова — низкую.
* **Zero-Width символы** — невидимые символы Юникода (шириной 0 пикселей). Их вставляют в текст как «водяные знаки» для отслеживания источников утечек.

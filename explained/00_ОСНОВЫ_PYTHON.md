## 2. Переменные — «коробки с именем»

```python
MAX_LOG_LINES = 25          # положили число 25 в коробку с именем MAX_LOG_LINES
```

**Правила именования (договорённость, не закон):**

| Как написано | Что значит |
|---|---|
| `МАЛЕНЬКИМИ_БУКВАМИ` → `max_lines` | обычная переменная |
| `ЗАГЛАВНЫМИ` → `MAX_LOG_LINES` | **константа** — значение, которое не меняют |
| `_с_подчёркиванием` → `_log_lock` | «внутренняя» штука, снаружи файла её трогать не надо |
| `СловаСЗаглавной` → `GhostTimer` | **класс** (см. раздел 9) |

## 3. Типы данных

| Тип | Пример | Что это |
|---|---|---|
| `int` | `45` | целое число |
| `float` | `0.2` | дробное число |
| `str` | `"привет"` | строка (текст) |
| `bool` | `True` / `False` | да / нет |
| `None` | `None` | «ничего», пустота |
| `list` | `[1, 2, 3]` | список — можно менять |
| `tuple` | `(1, 2)` | кортеж — как список, но менять нельзя |

Так принято записывать системные константы Windows. `0x10` = 16, `0xFF` = 255.

## 4. f-строки — подстановка значений в текст

```python
sec = 45
print(f"Удаление через {sec} сек")      # → Удаление через 45 сек
print(f"{3.14159:.2f}")                 # → 3.14   (:.2f = 2 знака после запятой)
print(f"{'abc':<10}|")                  # → abc       |  (:<10 = выровнять влево на 10 символов)
```

Буква `f` перед кавычкой значит: «всё в `{фигурных скобках}` — вычисли и вставь».

## 6. Условия `if / elif / else`

```python
if key == "b":
    очистить()
elif key == "p":     # elif = "иначе, если"
    паника()
else:
    ничего()
```

**Тернарный оператор** — `if` в одну строку:
```python
state = "ВКЛ" if enabled else "ВЫКЛ"
#        ↑ если True     ↑ если False
```

**Проверка «есть ли внутри»:**
```python
if key in ("1", "2", "3"):    # key равен одному из этих?
if "http" in text:            # есть ли "http" в тексте?
```

**Что считается «ложью»:** `None`, `0`, `""` (пустая строка), `[]` (пустой список), `False`.
Поэтому `if not text:` значит «если текста нет или он пустой».

## 7. Циклы

```python
for line in _log_lines:       # пройтись по каждому элементу
```

## 8. Функции

```python
def add_log(msg: str) -> None:
    """Добавляет строку в лог."""
    print(msg)
```

- `def` — объявляем функцию
- `msg` — **параметр** (то, что передают внутрь)
- `: str` — **подсказка типа**: «сюда ожидается строка». Python её НЕ проверяет, это для людей и редактора
- `-> None` — что функция возвращает
- `return` — вернуть результат и выйти из функции

**Значения по умолчанию:**
```python
def read_clipboard_text(retries: int = 5): ...
read_clipboard_text()      # retries будет 5
read_clipboard_text(10)    # retries будет 10
```

**Именованные аргументы:** `log_audit(event="X", process="Y")` — указываем, какой параметр чему равен.

**Возврат нескольких значений** (на самом деле возвращается кортеж):
```python
def f():
    return "текст", 3
cleaned, count = f()   # распаковка: cleaned="текст", count=3
```

**lambda** — функция без имени, в одну строку:
```python
lambda m: add_log(m)
# то же самое, что:
def _без_имени(m):
    return add_log(m)
```

**Функцию можно передать как значение** (без скобок!):
```python
TrayManager(on_panic=handle_panic)   # передали САМУ функцию, а не результат её вызова
```
Потом `TrayManager` сам её вызовет, когда нажмут кнопку. Это называется **callback** (обратный вызов).

## 9. Классы и объекты

Класс — это **чертёж**. Объект — **вещь, сделанная по чертежу**.

```python
class GhostTimer:                 # чертёж таймера
    def __init__(self):           # __init__ запускается при создании объекта
        self._armed = False       # self = "этот конкретный объект"

    def is_armed(self):           # метод = функция внутри класса
        return self._armed

ghost_timer = GhostTimer()        # сделали объект по чертежу
ghost_timer.is_armed()            # вызвали его метод → False
```

- `self` — ссылка на сам объект. Через `self.что_то` объект хранит свои данные
- `self._armed` — **атрибут** (переменная внутри объекта)

**`@dataclass`** — декоратор (см. ниже), который автоматически дописывает к классу служебный код.

**Декоратор** — строчка `@что_то` над функцией или классом. Она «оборачивает» его, добавляя поведение.

## 14. Потоки (threading) — делать несколько дел одновременно

GhostClip одновременно: следит за буфером, ждёт нажатия клавиш, тикает таймер, держит иконку в трее.
Для этого каждое дело работает в своём **потоке**.

```python
threading.Thread(target=run_key_listener, daemon=True).start()
# target   = какую функцию запустить в отдельном потоке
# daemon   = поток умрёт сам, когда закроется основная программа
# .start() = поехали
```

**Замок (Lock)** — чтобы два потока не меняли одни данные одновременно и не устроили кашу:
```python
_lock = threading.Lock()
with _lock:
    # пока один поток здесь — остальные ждут у входа
```

**Event** — флажок, который один поток поднимает, а другой проверяет.

## 18. ctypes — разговор с Windows напрямую

Python сам по себе не умеет работать с буфером обмена или треем Windows.
`ctypes` позволяет вызывать функции из системных библиотек Windows (`user32.dll`, `kernel32.dll`).

```python
user32 = ctypes.windll.user32          # подключили библиотеку Windows
user32.OpenClipboard(None)             # вызвали её функцию
```

`argtypes` / `restype` — объясняем Python, какие типы данных функция Windows принимает и возвращает.
Без этого на 64-битной Windows могут быть падения.

**Handle (дескриптор, HWND, HANDLE)** — номерок, который Windows выдаёт на окно/память/процесс.
Как номерок в гардеробе: сама вещь у Windows, а у тебя только номер.

## 19. Регулярные выражения (`re`)

Шаблоны для поиска текста.

```python
re.compile(r"sk-[a-zA-Z0-9_\-]{20,}")
```
| Кусок | Значит |
|---|---|
| `sk-` | буквально «sk-» |
| `[a-zA-Z0-9]` | одна латинская буква или цифра |
| `{20,}` | 20 или больше раз |
| `\d` | цифра |
| `\s` | пробел/перенос строки |
| `\b` | граница слова |
| `?` | необязательно |
| `r"..."` | «сырая строка» — `\` не считается спецсимволом |

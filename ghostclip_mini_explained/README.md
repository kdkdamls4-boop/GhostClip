# 🎓 GhostClip Mini Explained — Учебная версия из 7 файлов

Это **полная рабочая копия компактной версии** GhostClip Mini, разбитая ровно на **7 лёгких файлов**.
В каждом файле почти каждая строчка подробно объяснена комментариями на русском языке.

---

## 🗺️ Карта из 7 файлов

| № | Файл | Строк | За что отвечает |
|:---:|---|:---:|---|
| 1 | [config.py](config.py) | ~50 | Хранение настроек `[1-6]` и запись в файл журнала `clipboard_access.log` |
| 2 | [cleaner.py](cleaner.py) | ~50 | Удаление трекинг-меток из URL (`utm_*`, `fbclid`, `si`) и невидимых символов Zero-Width |
| 3 | [detector.py](detector.py) | ~55 | Поиск секретов: ключи OpenAI, AWS, токены GitHub, карты (алгоритм Луна), пароли |
| 4 | [clipboard.py](clipboard.py) | ~65 | Взаимодействие с буфером обмена Windows через `ctypes` (0% CPU) и имя активного окна |
| 5 | [shredder.py](shredder.py) | ~60 | Затирка буфера нулями, экстренная паника (очистка Win+V) и таймер на 45 секунд |
| 6 | [tray.py](tray.py) | ~110 | Иконка в системном трее Windows, ПКМ-меню, balloon-уведомления и сворачивание `[_]` |
| 7 | [main.py](main.py) | ~130 | Главный цикл, отрисовка дашборда и моментальные клавиши `[1-6]`, `[B]`, `[P]`, `[T]`, `[Q]` |

---

## ▶️ Запуск учебной версии:

```bash
python ghostclip_mini_explained/main.py
```
*(Работает абсолютно так же, как и чистая версия в `ghostclip_mini/`)*

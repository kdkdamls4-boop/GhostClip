# ==============================================================================
# GhostClip Python (Легкая версия)
# ==============================================================================
# Проект построен исключительно на стандартной библиотеке Python 3:
#   - ctypes (прямой вызов Win32 API для буфера и процессов)
#   - urllib.parse (парсинг и безопасная очистка URL)
#   - re (регулярные выражения для поиска секретов)
#   - threading (фоновый мониторинг и отсчет таймера)
#   - subprocess (вызов WinRT через PowerShell для истории Win+V)
#
# Сторонние зависимости (pip install ...) НЕ ТРЕБУЮТСЯ!
# Для запуска достаточно просто установленного Python 3.8+ на Windows 10/11:
#   python ghostclip.py
# ==============================================================================
